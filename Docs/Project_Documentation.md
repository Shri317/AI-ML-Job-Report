# Project Documentation

## 1. Project Overview

The **AI & ML Job Report** is an interactive Power BI dashboard designed to analyze job-market information related to Artificial Intelligence and Machine Learning.

## 2. Objectives

- Analyze job availability.
- Compare salary levels.
- Study experience-wise hiring patterns.
- Identify important job locations.
- Compare companies and job roles.
- Analyze frequently required skills.
- Understand remote and hybrid work patterns.

## 3. Data Preparation

The data is prepared and transformed using Power Query before being loaded into the Power BI model.

Typical preparation steps include:
- Removing duplicate records
- Handling missing/invalid values
- Correcting data types
- Standardizing categorical values
- Creating useful date attributes
- Preparing dimension and fact tables

## 4. Data Modeling

The report uses fact and dimension tables to organize job, company, location, date and skill information.

## 5. Dashboard Pages

### Overview
Provides the overall job-market summary and key KPIs.

### Location Insights
Provides geographical and experience-level analysis.

### Company & Role Insights
Provides company, job-role, salary and work-arrangement analysis.

### Skills & Hiring Insights
Provides skill-demand and experience-level hiring analysis.

Add the final insights obtained from the completed dashboard here after validation of the full dataset.

Suggested format:

- **Salary:** Describe the experience level/role with the highest average salary.
- **Location:** Identify the region/country/city with notable job activity.
- **Skills:** Identify the most frequently required skills.

## 7. Conclusion

The dashboard provides a centralized analytical view of the AI & ML job market. It combines data modeling, Power Query transformations, DAX calculations and interactive Power BI visualizations to support exploration of salary, hiring, skills, companies, locations and work arrangements.
